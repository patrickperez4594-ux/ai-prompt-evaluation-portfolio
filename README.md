# AI Prompt Evaluation Portfolio

Practical AI evaluation case studies exploring prompt design, annotation quality, evidence calibration, and human review.

## Projects

1. **[Case Study #1 — Blueberry Nutrition Prompt Evaluation](case-studies/01-blueberry-nutrition/README.md)**  
   A three-prompt comparison of nutrition explanations, scored on a preliminary five-criterion rubric. The strongest prompt received 24/25 in a subjective evaluation.

2. **[Case Study #2 — AI Data Annotation & Quality Assurance](case-studies/02-ai-data-annotation-qa/README.md)**  
   Six ChatGPT runs across 24 synthetic customer reviews, including a harder challenge set, human-label adjudication, error analysis, and quality-assurance checks. The [full report](case-studies/02-ai-data-annotation-qa/CASE_STUDY.md) and [supporting dataset and prompts](case-studies/02-ai-data-annotation-qa/supporting-files.zip) are included.

Both studies are exploratory learning projects. Reported results are limited to the recorded examples and should not be interpreted as validated general-purpose model accuracy.
